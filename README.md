# 🎓 Final Year Project Management System

A simple **Java-based console application** designed to help manage final-year student project teams, project assignments, progress updates, seminars, and student marks.

## 📌 Project Overview

The **Final Year Project Management System** provides a structured way to manage student teams and their academic projects.

The application allows users to create teams, add students, assign projects, record project progress, record marks, and display complete team information through a menu-driven console interface.

## ✨ Features

* 👥 **Create Team**

  * Create and store final-year project teams.

* 👨‍🎓 **Add Student**

  * Add students to an existing team.
  * Store student roll number and name.

* 📋 **Assign Project**

  * Assign a project title and description to a team.

* 📈 **Add Project Progress**

  * Record progress notes for assigned projects.
  * Record seminar-related information.

* 📝 **Record Marks**

  * Enter marks for every student in a team.

* 📊 **Show Teams**

  * Display:

    * Team name
    * Team members
    * Student marks
    * Project details
    * Project progress
    * Seminar information

* 🚪 **Exit**

  * Safely exit the application.

## 🛠️ Technologies Used

* **Java**
* **Java Collections Framework**
* `ArrayList`
* `HashMap`
* `Scanner`
* Object-Oriented Programming (OOP)

## 🧩 Main Classes

### `Student`

Stores student information:

* Roll number
* Name
* Marks

### `Project`

Stores project information:

* Project title
* Project description
* Progress notes

### `Team`

Stores:

* Team name
* List of students
* Assigned project
* Seminar information

### `Main`

Contains the main program and menu-driven operations for managing teams and projects.
